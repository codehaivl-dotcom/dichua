# Đi Chùa Online — Game Design & Technical Specification

**Status:** PRE-PRODUCTION · Spec v1.0 (2026-11-01)

A Vietnamese pagoda-inspired multiplayer social sanctuary for browsers and mobile browsers, designed for calm presence rather than competition.

**Start here:** [AGENTS.md](AGENTS.md) and [docs/00-PRODUCT-BRIEF.md](docs/00-PRODUCT-BRIEF.md). The written specification is authoritative; code and art must not invent unapproved features.

**Visual direction:** 3D third-person, textured mid-poly / stylized semi-realistic at the level of detail shown by the owner's 2026-11-01 reference screenshot. Low-poly is **not** mandatory. The reference concerns presentation quality, camera feel, spatial density, and character readability—not the urban architecture in that screenshot.

**Build priorities:** single-player playable vertical slice -> authoritative multiplayer rooms -> performance/mobile -> accessibility and launch. Public repository: never commit secrets.

See [implementation roadmap](docs/12-DELIVERY-PLAN.md) and [acceptance tests](docs/11-QA-ACCEPTANCE.md).

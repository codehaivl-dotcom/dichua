# 04 — Player experience, UI, HUD, avatar

## Screens
S01 ENTRY: game title, real 3D preview/fallback image, “Vào chùa”, “Cách chơi”, mute, privacy/terms, 18+ self-attestation. No forced registration.
S02 AVATAR PICK: 4 human-height 3D presets sharing humanoid rig, one tap selection; neutral unisex options and skin/hair/outfit variation, no gender requirement; Enter.
S03 LOADING: real progress or honest spinner; Retry/Offline if server unavailable, never fake 100%.
S04 WORLD: third-person avatar+scene, mini-map small, nearby person count SERVER-verified, chat area, action contextual button, mini task clue, friend notifications; HUD lightweight, avoids blocking the architecture.
S05 NPC/ACTIVITY: dialog / mini-game overlay occupying <=45% desktop, <=70% phone viewport and always escapable; privacy disclaimer in folk activities.
S06 FRIENDS: tabs Online, Lời mời, Tin nhắn; actions join room, request, remove, block, report.
S07 JOURNAL: up to 20 authored result IDs from past solo/pair cards and cut-ties completed; only owner sees.
S08 PHOTO: camera orbit/framing, local image save after opt-in poses; no auto cloud uploads.
S09 SETTINGS: sounds, SFX, sensitivity, camera inverse, visual quality auto/low/medium/high, show chat, hide remote avatars, privacy, leave room.
S10 ERROR/RECONNECT: connection state and retry, local scene optionally continues (network actions disabled until reconnection).
No finance shop, inventory, combat HUD, XP bars, fake matchmaking results, advertisement in hall.

## Desktop controls
WASD/arrow move, Shift brisk walk, right-drag rotate, wheel zoom, E contextual interact, F emote radial, Enter chat when outside Z_HALL, Esc closes current modal / menu, M mute; Tab normal keyboard UI navigation. UI focus stops game WASD. All menus keyboard accessible; input sanitizer for chat.

## Mobile controls
Left virtual joystick 112px, right scene drag camera, bottom-right contextual action 72px, secondary wave 48px, chat/friend/menu >=48px touch areas, pinch zoom or +/- fallback. Phone portrait and landscape responsive. Safe-area insets. Orientation change does not reset room or seat, pointercancel clears joystick state. No pointer lock mandatory, no hover-only actions.

## Camera
Third-person behind player default 4.8m; range 3–7m; vertical FOV 58 desktop / 62 mobile; yaw 360; pitch 10–55 downward; camera collision shortens arm without clipping hall or roof. Natural avatar scale as reference screenshot. When in pair ritual, 2–3 sec optional shared framing skip-able; not forced romantic camera. Photo camera is client-side only.

## HUD hierarchy
Top-left location + small mini-map, top-right menu/audio/Friends, bottom-left hints+chat minimized, bottom-center context hint, right activity invitation card. Proximity bubbles max 2 lines overhead to prevent crowd occlusion. No large quests taking more than 1/8 screen.

## UX copy
“Vào thăm chùa”, “Xin quẻ tình duyên”, “Mời xin quẻ đôi”, “Dâng sao tượng trưng”, “Chuyện dân gian: Cắt duyên âm”, “Bạn bè”, “Lời mời”, “Nhắn tin”, “Chặn”, “Báo cáo”, “Rời chùa”.
System toasts 2–4s. Errors map code to explicit localized phrase, no raw exceptions. Clear difference between real avatar, NPC and offline mode.

## Accessibility
Text contrast >=4.5:1, button >=44x44 CSS pixels desktop and >=48x48 mobile. Font supports full Vietnamese, caption bell/animation prompts, colorblind-aware status. Adjustable UI scale; reduced motion; scroll-independent touch; alternative press button for hold/star puzzle; skip all cinematics. Auto sound off until browser gesture. Chat visible only if opted in to display; always report/block.

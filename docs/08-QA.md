# 08 — Definition of Done and acceptance tests

The product is accepted by **actual playable browser runs**; screenshots/render mockups/green test dashboards alone never qualify.

## Release-blocking E2E scenarios (IDs)
- E01 Desktop open -> guest -> avatar -> 3D third-person world; walk/rotate/collide -> leave -> rejoin without orphan scene.
- E02 Mobile portrait + landscape: joystick, camera, tap interaction, resize no session loss; sound mute works.
- E03 Real movement/nav: gate -> hall -> mat -> stand -> incense/bell, no clipping or fake interact.
- E04 Solo love oracle: valid card chosen by SERVER from pool, save private, cancel/retry idempotent.
- E05 Pair oracle: two independent browsers see each other, invite/accept, both READY, same card, decline/cancel/timeout path.
- E06 Star offering: four wish categories, shader/animation, 8 sockets and 45s expiry, full-socket private completion.
- E07 Cut-ties: three stages correct order, all ring seeds solvable <=6 clicks, skip option, reconnect partial progress, no ghost/curse claim.
- E08 Chat proximity: inside 16m delivered, 17m not; quiet hall prevents nearby chat; link/profanity/spam filters; mute/block enforced.
- E09 Friends: request, accept, reject, expiry, duplicate, offline list, leave/rejoin, mutual DM, remove and block, join friend room capacity.
- E10 Tea/photo: invite 30s, 4 seat limit, decline, local capture respecting opt-out.
- E11 Server authority: forged pos/action/card/guest IDs rejected; duplicate command no double reward/result/seat; dual-tab only one controller.
- E12 Network: reconnect within 8s, past 8s new join, server restart, no ghost avatars or leaked chairs, no false “online N”.
- E13 Safety: 18+ age gate (self attest), report works, deletion endpoint works, journal private, no public identifier or raw chat logs in analytics.
- E14 Assets: Vietnamese architecture is distinct from Chinese/Japanese/European generic temples; mid-poly/textured 3D, owner fidelity visual review; all licensed.
- E15 Load: at least 30 WS scripted clients in a room for 10 min chat+move+pair/seat loops, no OOM, loop state consistency; 50 conditional.
- E16 Quality: desktop target >=50fps and mid-range phone >=30fps in standard 20–30 population; capture FPS + triangles + calls + memory + network; published as measured not guessed.

## Unit + integration
State transitions deterministic; fortune dataset validation: correct pools/counts/no placeholders; seeded RNG selection only in test, cryptographic randomness prod; ring puzzle generation; chat grapheme counts and rate; server zone chat rules; friend canonical DB uniqueness; invitation race; seat atomicity; star socket timers; privacy deletion; screenshot permission. Contract tests client/server schema version mismatch and invalid messages.

## Real browser test matrix
Chrome Windows desktop, Firefox Windows desktop, Chrome Android mid-tier, Safari iOS mid-tier; desktop mouse/keyboard, phone landscape/portrait, lower-performance preset; test HTTPS and WSS. Note supported exact versions in RELEASE_NOTES. No claiming Safari coverage if device not tested.

## Evidence required per release
Commit SHA; deployed URL; exact start/build/test commands and exit status; Playwright trace; 2 separate browser contexts WS trace; 6 runtime screenshots of zones; video pair ritual and friend flow; FPS/draw call/device matrix; data/privacy audit list; unresolved defect list. “PASS” = observed evidence. “UNVERIFIED” != PASS.

## Severity
P0 security/privacy leak, fake multiplayer, broken friend block, pay-to-spiritual scare, crash on load.
P1 core ritual unreachable, card desync, mobile controls impossible, reconnect ghost, social feature broken.
P2 clip/art imperfect, low-end FPS below target, nonblocking text error.
Public launch requires zero P0/P1 open; P2 owner decides with transparency.

## Offline solo fallback
Can play local explore/ritual preview in disconnected mode clearly marked “Chơi một mình”; no fake chat, friend presence, shareable persistent quẻ state or multiplayer claiming success. Social flows require real server.

# 08 — Definition of Done and acceptance tests

The product is accepted by **actual playable browser runs**; screenshots/render mockups/green test dashboards alone never qualify.

## Release-blocking E2E scenarios (IDs)
- E01 Open Spawn place with existing authenticated Spawn player/display name -> 3D third-person world; walk/rotate/collide -> leave/rejoin without duplicate avatar. No separate guest form.
- E02 Mobile portrait + landscape: joystick, camera, tap interaction, resize no session loss; sound mute works.
- E03 Real movement/nav: gate -> hall -> mat -> stand -> incense/bell, no clipping or fake interact.
- E04 Solo love oracle: valid card chosen by SERVER from pool, save private, cancel/retry idempotent.
- E05 Pair oracle: two independent browsers see each other, invite/accept, both READY, same card, decline/cancel/timeout path.
- E06 Star offering: four wish categories, shader/animation, 8 sockets and 45s expiry, full-socket private completion.
- E07 Cut-ties: three stages correct order, all ring seeds solvable <=6 clicks, skip option, reconnect partial progress, no ghost/curse claim.
- E08 Chat proximity: inside 16m delivered, 17m not; quiet hall prevents nearby chat; link/profanity/spam filters; mute/block enforced.
- E09 Verify existing Spawn friends: request, accept, reject, offline list, mutual DM, remove/block, join room/party; do not implement second friend/DM stack. Unsupported hooks = PENDING_SPAWN_API.
- E10 Tea/photo: invite 30s, 4 seat limit, decline, local capture respecting opt-out.
- E11 Using Spawn's authoritative game action APIs: forged card/action rejected, duplicate commandId no double reward/result/seat, multi-session limits inherited from Spawn; record actual API proof or mark PENDING.
- E12 Spawn-native reconnect/join/leave per actual platform behavior (do not assume 8s grace), no ghost avatars/seat locks, no false “online N”.
- E13 Safety: NO separate 18+ gate; verify Spawn youth safeguards, report/block/mute and privacy/account deletion policy; journal private; no personal details in quẻ/global. Disable affected social feature if protections unavailable.
- E14 Assets: Vietnamese architecture is distinct from Chinese/Japanese/European generic temples; mid-poly/textured 3D, owner fidelity visual review; all licensed.
- E15 Load: at least 30 authentic Spawn room participants (or approved Spawn load simulation) for 10 min movement/interaction; no memory leak, consistent activity state; 50 only after evidence.
- E16 Quality: desktop target >=50fps and mid-range phone >=30fps in standard 20–30 population; capture FPS + triangles + calls + memory + network; published as measured not guessed.

## Unit + integration
State transitions deterministic; fortune data validation: old 12/12 pools + new 32/9 separate pools + no placeholders, tier weights 72/22/5/1; seeded RNG only in tests and trusted Spawn RNG in production; 6 micro-games win/cancel paths; invitation race; Spawn zone chat/safety integration; block state; star socket timers; private journal; photo consent. Do not test a non-existent self-hosted DB. Contract tests for actual Spawn API signatures, permissions and failure cases; no invented HTTP/WS endpoint tests.

## Real browser test matrix
Chrome Windows desktop, Firefox Windows desktop, Chrome Android mid-tier, Safari iOS mid-tier; desktop mouse/keyboard, phone landscape/portrait, lower-performance preset; test HTTPS and WSS. Note supported exact versions in RELEASE_NOTES. No claiming Safari coverage if device not tested.

## Evidence required per release
Commit SHA; deployed URL; exact start/build/test commands and exit status; browser/engine trace where supported; 2 independent Spawn player-session traces; 6 runtime screenshots of zones; video pair ritual and friend flow; FPS/draw call/device matrix; data/privacy audit list; unresolved defect list. “PASS” = observed evidence. “UNVERIFIED” != PASS.

## Severity
P0 security/privacy leak, fake multiplayer, broken friend block, pay-to-spiritual scare, crash on load.
P1 core ritual unreachable, card desync, mobile controls impossible, reconnect ghost, social feature broken.
P2 clip/art imperfect, low-end FPS below target, nonblocking text error.
Public launch requires zero P0/P1 open; P2 owner decides with transparency.

## Offline solo fallback
Can play local explore/ritual preview in disconnected mode clearly marked “Chơi một mình”; no fake chat, friend presence, shareable persistent quẻ state or multiplayer claiming success. Social flows require real Spawn multi-user runtime.
